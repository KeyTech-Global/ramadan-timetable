# 🌙 Ramadan Timetable Website

A complete Ramadan website with:
- Accurate Sehri and Iftar times for any location worldwide
- 28 language translations
- Auto theme based on sunrise/sunset
- Download/share timetable as JPEG or text
- Daily, weekly, monthly, and custom date ranges

## 🚀 Features
- Search any city worldwide with suggestions
- Automatic location detection
- Real-time prayer times from Aladhan API
- Beautiful UI with light/dark auto theme
- Multi-language support (28 languages)
- Download timetable as image
- Share via WhatsApp, copy text

## 📱 Technologies Used
- HTML5, CSS3, JavaScript
- Aladhan API (prayer times)
- Open-Meteo API (city search)
- Sunrise-Sunset API (auto theme)
- html2canvas (image generation)
